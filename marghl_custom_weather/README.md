# Marghl Custom Weather Areas

- `/weather_area_add <Area-ID>`: Schaltet Wetter in einer bestehenden Area aus.
- `/weather_area_remove <Area-ID>`: Schaltet Wetter dort wieder ein.
- `/weather_area_list`: Listet alle wetterfreien Areas auf.

Alle Befehle erfordern das Privileg `server`. Die Auswahl bleibt dauerhaft im
bisherigen Mod-Speicher erhalten. Wird eine Area geloescht, verschwindet auch
ihr Wetter-Eintrag.
